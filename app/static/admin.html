Apple Maps Server API

The Apple key (Team ID, Key ID and the .p8 file) is set in this service's settings on the machine, never here. A new token costs no quota; it checks that Apple accepts the key.

Try it

One route through the service as an app's call goes: the cache first, then Apple within the quota. "Ask Apple" skips the cache and spends one Apple call.

Apple's quota

Apple allows 25,000 calls a day for the whole Apple Developer team. When both the Mac mini and the NAS run this service, their daily limits together must stay under 25,000 (e.g. 20,000 on the Mac, 4,500 on the NAS).
